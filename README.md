# molee.study · 修习录

一个面向**所有学生**的本地学习指挥台：课程表、章节任务、考试倒计时、错题复习与个性化桌面，全部装在一个界面里。

界面沿用原来的火影忍道风格，但**不包含任何真实课程、教师、班级或个人信息**，打开即可用，也可以完全替换成自己的课程。

## 功能

- **课程表**：按周查看，支持一门课连续多周排课，点击课程卡片即可编辑
- **章节任务**：每门课可拆成任意章节，按课时加权计算进度，支持笔记与三项子任务
- **考试倒计时**：逐科设置考试时间，支持系统语音播报剩余时间
- **错题卷轴**：自定义 A/B 面错题卡，可附图片与文档，支持翻面复习
- **课程管理**：添加、改名、删除课程；删除时级联清理章节、课表和错题
- **AI 辅助导入**：内置提示词，复制给任意 AI，把返回的 JSON 粘回来即可
- **新手引导**：首次启动 4 步向导；右下角「?」随时查看完整说明
- **备份迁移**：导出 / 导入 JSON，换电脑或分享给同学
- **个性化中心**：昵称问候、6 套氛围色、背景图、字号、卡片透明度、轮播频率、人物 / 语录开关、任务名称与自定义语录

## 快速开始

### 浏览器预览

```bash
# 任意静态服务器均可
npx serve .
```

### 桌面端（Electron）

```bash
npm install
npm start
```

## 数据与隐私

- 全部数据保存在浏览器 / Electron 的 **localStorage** 中，错题附件保存在 **IndexedDB**
- 不联网、不上传、不注册、不内置任何 API Key
- AI 辅助导入使用的是**你自己的 AI 账号**，程序只负责校验和入库
- 清理浏览器数据会丢失记录，换设备前请先「导出备份」

## 个性化

左侧栏最下方的「个性化」可以随时打开设置中心，所有改动都会即时预览并保存在本机。

- **主页称呼**：填写昵称后，首页问候会显示「下午好，小林 · 今日修习」
- **氛围色**：樱粉、朱砂、青竹、天青、紫藤、暮金，联动导航、按钮、滑块和页面底色
- **背景图**：可切换内置背景或上传自己的图片；支持透明度、大小、左右 / 上下位置微调
- **界面**：卡片透明度可调；字号提供小 / 标准 / 大 / 特大四档
- **显示控制**：人物插画与励志语录可分别隐藏；人物轮播可选 1 / 5 / 10 / 30 分钟
- **章节小任务**：三项固定任务的名称可以改成自己的学习习惯
- **我的语录**：逐条添加、删除自己的句子和署名，或一键恢复内置忍者语录
- **全部恢复默认**：一次撤销上面所有个性化设置

上传的背景图片会先在本地压缩再保存，不会上传到任何服务器。单张原图请不要超过 25MB；如果浏览器本地空间不足，程序会保留原设置并给出提示。

## AI 辅助导入

1. 「学习设置 → AI / 数据导入」
2. 点「复制提示词」，连同教学大纲、课表截图或教务系统导出的表格一起发给 AI
3. 把 AI 返回的整段内容粘回程序
4. 点「校验并预览」，红色提示行会被跳过
5. 选择「追加」或「替换」，确认导入

支持直接粘贴带 ```json 代码块的回复，程序会自动剥离。

## 素材说明

`assets/companions` 与 `assets/backgrounds` 中的图片来自第三方作品，仅作个人学习演示使用。

如果要**公开发布**这个项目，请二选一：

- 将仓库设为私有
- 用自己拥有授权的图片替换 `assets/` 下的同名文件（保持文件名与比例不变即可）

## 已知限制

- 不直接解析 PDF / Word：不同学校格式差异太大，推荐用 AI 辅助导入
- 备份不包含 IndexedDB 中的错题附件文件
- 桌面端打包产物未做代码签名
